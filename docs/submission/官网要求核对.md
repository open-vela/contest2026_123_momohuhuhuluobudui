## 不得误填或夸大

- 不宣称主人/身份识别；目前只做人脸检测、画框和人数统计。
- 不宣称 KWS、摄像头手势或 MENU/UP 按键功能。
- 不填写未经标准数据集测得的准确率、误报率或漏报率。
- 不填写未经仪器测得的功耗或未经记录的长稳时长。
- 开发期 Coding Skill 不描述成板端 `/data/agent/skills/` 运行时 Skill。
- 不在视频、照片、日志或表单中暴露 Token、密钥和私人信息。
