# AgentGuard 演示视频脚本（目标 4 分 30 秒）

## 0:00–0:25 开场

画面：开发板、电脑和连接线全景，随后给开发板 LCD 特写。

旁白：AgentGuard 是基于 openvela 和 ESP-DL 的桌面健康与隐私守护终端。摄像头画面只在开发板本地处理，电脑只接收结构化事件。

## 0:25–1:10 ESP-DL 人脸检测

1. 空场景，展示 `FACE:0`。
2. 放入一张正面人脸，展示 `FACE:1` 和一个检测框。
3. 放入第二张脸，展示 `FACE:2` 和两个检测框。

旁白：算法层尽量保留 ESP-DL 官方实现，项目用一层兼容代码接入 NuttX/openvela。系统只检测人数，不做人脸身份识别。

## 1:10–2:15 久坐提醒与确认

1. 运行 `cd monitor && python3 run_demo.py`，展示自动打开的本地统计面板。
2. 按住 BOOT 至少 8 秒后松开，展示 Demo 已开启。
3. 单人保持在画面中约 20 秒。
4. 展示开发板 `STAND UP` 和久坐灯效，以及电脑桌面通知。
5. 短按 BOOT，展示 `acknowledged`，提醒被确认。

旁白：正式模式使用正常久坐阈值；Demo 只为在短视频中完成验证。无人时计时暂停，短按可以确认本次提醒。

## 2:15–3:20 隐私保护

1. 按住 BOOT 3–7 秒后松开，开启隐私模式。
2. 保持一人，说明隐私处于待命状态。
3. 第二人进入画面，展示 LCD 隐私状态、绿色 Power LED 双闪和电脑不透明遮罩。
4. 第二人移出，展示遮罩恢复。

旁白：电脑没有接收摄像头图像，只根据板端 `blur_screen` 事件显示遮罩；USB 断线也不会阻塞板端检测。

## 3:20–3:50 事件统计

展示浏览器中的实时面板：

```bash
cd monitor
python3 run_demo.py
```

展示今日/累计的久坐提醒次数、确认次数、隐私触发次数和最近事件。可补充 CSV 导出：`python3 event_stats.py --csv agentguard-events.csv`。

旁白：事件同时以有界 JSONL 留存，便于回顾行为，又不会保存原始人脸画面。隐私次数只统计真正触发的遮罩，不把仅开启模式算作触发。

## 3:50–4:30 技术总结

画面：架构图、代码目录、测试通过结果和硬件运行画面交替。

旁白：openvela 提供 V4L2、LCD、任务、串口和 LittleFS 能力；ESP-DL 完成本地视觉推理；确定性策略负责健康与隐私规则；电脑安全代理提供通知和遮罩。项目包含板端与电脑端自动化测试，并针对摄像头、模型和 USB 异常设计安全降级。

结束语：AgentGuard 用本地 AI 把健康提醒和屏幕隐私保护整合到一个可运行的小型终端中。

## 拍摄注意

- 全片不超过 5 分钟，最好一镜到底录制核心功能，再剪入架构图。
- 录制前开启电脑通知权限并运行 USB 代理。
- 用能稳定检测的正面人脸、均匀光线和清晰站位。
- 不提主人识别、KWS、摄像头手势或未测量的准确率/功耗。
- 不拍摄 Token、私人通知、个人目录等敏感内容。
