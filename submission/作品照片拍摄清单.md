# AgentGuard 作品照片拍摄清单

| `02-开发板正面.jpg` | 开发板正面近照 | 摄像头、LCD、按键清楚 |
| `03-开发板背面.jpg` | 开发板背面近照 | 硬件实物完整 |

| `05-双人检测.jpg` | LCD 显示两张人脸 | `FACE:2` 与两个框清楚 |
| `06-久坐提醒.jpg` | LCD 久坐提示及绿色 Power LED | 提醒状态可辨认 |
| `07-隐私保护.jpg` | 开发板和电脑遮罩同框 | 电脑遮罩及板端状态清楚 |
