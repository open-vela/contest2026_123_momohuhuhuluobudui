# AgentGuard 演示视频拍摄清单（目标 4 分 30 秒）

视频必须控制在 5 分钟以内。建议先完整试演一次，再开始录制；核心功能尽量连续拍摄，架构图和测试结果可在后期剪入。

## 拍摄前准备

- [ ] 开发板通过 USB 连接电脑，LCD 摄像头画面正常。
- [ ] 空场景显示 `FACE:0`，单人和双人检测正常。
- [ ] 电脑允许 Python 显示桌面通知，并已安装 `python3-tk`。
- [ ] 关闭私人通知和无关窗口，不拍摄 Token、邮箱及个人目录。
- [ ] 在终端启动电脑端 monitor：

```bash
cd "/home/yhx/Desktop/openvela/contest2026_123_momohuhuhuluobudui/.worktrees/ai-error-safe-state/monitor"
python3 run_demo.py
```

正常情况下浏览器会自动打开 `http://127.0.0.1:8765`。保持终端运行，录制结束后按 `Ctrl+C` 停止。

## 0:00–0:25 开场

- [ ] 拍摄开发板、电脑和 USB 连接线全景。
- [ ] 给开发板 LCD 一个清楚的近景。

旁白：AgentGuard 是基于 openvela 和 ESP-DL 的桌面健康与隐私守护终端。摄像头画面只在开发板本地处理，电脑只接收结构化事件。

## 0:25–1:10 ESP-DL 人脸检测

- [ ] 空场景展示 `FACE:0`。
- [ ] 放入一张正面人脸，展示 `FACE:1` 和一个检测框。
- [ ] 放入第二张脸，展示 `FACE:2` 和两个检测框。

旁白：算法层尽量保留 ESP-DL 官方实现，通过兼容层接入 NuttX/openvela。系统只检测人数，不做人脸身份识别。

## 1:10–2:15 久坐提醒与确认

- [ ] 展示 monitor 自动打开的本地统计面板。
- [ ] 按住 BOOT 至少 8 秒后松开，确认底栏显示 `D:ON`。
- [ ] 单人保持在画面中约 20 秒。
- [ ] 拍到开发板 `STAND UP`、久坐灯效以及电脑桌面通知。
- [ ] 短按 BOOT，拍到 `acknowledged`，确认提醒被清除。

旁白：正式模式使用正常久坐阈值；Demo 模式用于在短视频内完成验证。无人时计时暂停，短按 BOOT 可以确认提醒。

## 2:15–3:20 隐私保护

- [ ] 按住 BOOT 3–7 秒后松开，开启隐私模式，确认底栏显示 `P:ON`。
- [ ] 保持一人，展示隐私待命状态。
- [ ] 第二人进入画面，拍到 LCD 隐私提示、绿色 Power LED 双闪和电脑全屏遮罩。
- [ ] 第二人移出，拍到电脑遮罩自动恢复。

旁白：电脑不接收摄像头图像，只根据板端发送的结构化 `blur_screen` 事件显示遮罩；USB 断线不会阻塞板端检测。

## 3:20–3:50 事件统计

- [ ] 展示浏览器统计面板中的久坐提醒、确认、隐私触发次数和最近事件。
- [ ] 确认画面中没有敏感路径、Token 或私人通知。

旁白：事件以有界 JSONL 留存，不保存原始人脸画面。隐私次数只统计真正触发的遮罩，不把仅开启模式计为触发。

## 3:50–4:30 技术总结

- [ ] 展示架构图、代码目录、测试结果和硬件运行画面。
- [ ] 结尾保持作品全景 2–3 秒。

旁白：openvela 提供 V4L2、LCD、任务、串口和 LittleFS 能力；ESP-DL 完成本地视觉推理；确定性策略负责健康与隐私规则；电脑安全代理提供通知、遮罩和事件统计。AgentGuard 用本地 AI 将健康提醒与屏幕隐私保护整合为可运行的小型终端。
